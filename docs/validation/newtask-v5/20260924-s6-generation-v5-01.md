# S6 一次多 worker 生成 v5-01：结果报告

> 用户口径（V5 计划 1.1 口径 12）：「我只需要做一次对拍 旧的16*3生成一致 之后就直接1次多worker生成10候选+3实际执行」。
> 本报告只如实记录那一次生成，不设门槛；本机（RTX 6000 Ada，sm_89）产物，单次运行，不做第二遍（口径 11/12，风险 #15）。

## 一、命令与环境

- 代码：`17867d2`（12.130，S4 快照已重导）；采样快照 `scripts/configs/newtask-v5/sampling_config.json`（sha256 前缀 `c45d4408a5b87d71`）。
- 命令（tmux 会话 `v5-gen`，日志 `artifacts/logs/v5-gen-v5-01.log`，`EXIT_CODE=0`）：
  `uv run --no-sync python -m scripts.parity.v5_generation pipeline --run-id v5-01 --release newtask-v5 --draw-workers 8 --draw-gpus 0,1 --workers 8 --rollout-gpu 0 --official-root artifacts/train-parity/local-smoke-01/official-src`
- 墙钟：抽签约 5 分钟；实跑第 0 轮 48 局 749 s，递补 4 轮 65～86 s；总计约 25 分钟。同期本机另有 V1 两侧各 1 个单 worker 在 GPU 1 上运行。
- 生成后补跑 `v4_specs reselect`，得到 `scripts/configs/newtask-v5/v5-01/specs.selected.jsonl`（48 条，含递补替换）。

  VideoPlaceButton 6、VideoPlaceOrder 13、PickHighlight 2；其余 10 个环境 10 次尝试全部成功。
