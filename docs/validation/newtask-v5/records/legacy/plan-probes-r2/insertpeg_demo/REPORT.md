## 规则（V5 计划 1.4 的 L24～L29 结论）

4 根杆一个循环、放在 obj/dir 之前、同一套规则：原生判据（离孔板中心 > 0.06、离已放杆根 > 0.075）→ 通过后才抽 yaw（±180°）→
杆与孔板轮廓净距 > 0.01 → 与每根已放杆轮廓净距 > 0.03（严格不等号，有向矩形精确距离）；最多 512 次；目标恒为 peg_0。

## 结果（10 局，seed 取 v4-01 的 InsertPeg 10 个 seed）

- 成功 **4/10**（V4 同一组 seed 2/10）。
- 间隔全部成立：两两最小轮廓间隔 0.0304 > 0.03，离孔板最小 0.0165 > 0.01；静置 20 步最大横移 0.001 mm；演示中没有邻杆被抬起。
- 10 局布局与 V5 离线原型逐位一致，确认用的是 V5 抽样顺序。

失败 6 局的诱因：

| 诱因 | 局数 | 说明 |
|---|---|---|
| 目标重叠 / 邻杆在夹爪闭合区 / 压孔板 | 0 / 0 / 0 | 间隔规则负责的三类全部清零（V4 为 3 / 2 / 1） |
| 可达极限 | 2 | 抓取点离基座 0.832 / 0.815 m，都在杆区远边 x ≈ 0.2；本机实际极限约 0.80～0.81 m |
| 插入不到位 | 3 | 都是抓尾插头（obj=1），插完后插入端离孔板中心 0.051 / 0.071 / 0.074，判据 < 0.05；邻杆与孔板全程未动，是 `insert_peg` 求解器的问题 |
| 规划失败 | 1 | 抓取点离基座 0.53 m，抓取规划失败但没报错，插入阶段空转到 5000 步 |

## 离线估计（`reach_offline.json`，每种 400 局）

抓取点离基座 > 0.78 m 的比例：当前杆区（x ∈ [-0.2, 0.2]）16%；x 上界收到 0.15 → 5%；收到 0.1 → 0；布局失败都是 0。只收 y 基本没用。

## 判断

- 0.03 的轮廓间隔够用，间隔规则要解决的问题已全部解决。
- 剩余失败与间隔无关，分属两件事，各需用户另立决策：是否收窄杆区 x 上界（可达极限）；是否修 `insert_peg` 的插入不到位。
- 正式生成时本任务通过率按约 40% 留余量。
