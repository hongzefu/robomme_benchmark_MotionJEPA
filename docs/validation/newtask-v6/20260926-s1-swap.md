# V6 S1：VUS/BUS/VR 四档交换均匀化

本记录对应 V6 定稿对 VideoUnmaskSwap、ButtonUnmaskSwap 与 VideoRepick 的 S5/O4 实现和 M5(b) 藏物约束。代码集成在 `newtaskRelease-v5` 主树，分支草稿 `v6-draft-swap` 不推送。

## 改动

- VUS、BUS、VR 的新值运行分支统一覆盖 `xhard1..xhard4`，原 easy/medium/hard 路径保留。VUS/BUS 的 swap/pick 数由 `native.parameters.configs[当前档]` 提供，decision 中的每档 S5/O4 参数在取值点实际消费。
- 内环 S5 按碰撞预筛得到可行槽对图，优先使用参与次数最少且不立即撤销的搭档；外环 O4 均衡配对并在放置后重排序号。实际 swap 窗口起点会复核扫掠可行性。
- M5(b) 固定藏 cube 位置只从前三个内环容器选，第四个容器 `bin_3` 恒空；不保留 M5(a) 的四容器藏物范围。
- `native_blocks(release=...)` 区分历史 V4/V5 `xhard` 输出与 V6 四档输出。V5 snapshot 不改写；V6 的新 `parameters.configs` 和四档 decision 待完整源码集成后统一抽取。
