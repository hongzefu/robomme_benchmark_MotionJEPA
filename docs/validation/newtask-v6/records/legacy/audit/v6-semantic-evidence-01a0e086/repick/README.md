# VideoRepick 离线语义与视觉复核

源码锚点：`0a3f989b0dfcff12a3cbb34a8112cb56864c7ee8`。只读既有 HDF5 和视频，没有运行环境、reset 或生成轨迹。

## 结论

- 七档各三条，共 21 条 HDF5，演示抓取均只有一次；执行次数与各条规格一致。
- 其中 18 条执行次数大于一次，`setup/task_goal` 的第二条话术含 `previously picked up twice/{word} times`，把次数放进过去演示的从句，存在语义歧义。实际视频也显示这段话。
- 新值四档各三条，共 12 条视频的 12 次演示抓取及 43 次执行抓取，逐段取开始帧和结束前 12 帧，共 110 帧。已目视实际 RGB、原始分割和目标分割三个并列面板，每条执行抓起的对象保持演示对象的分割颜色，未发现对象替换。原始场景同色方块不能单靠 RGB 认身份；此处借助同一视频固定的 actor 分割调色映射。
- 同 12 条视频的演示静止／交换阶段共 5266 帧，按初始目标分割的颜色中位值，在原始分割画面做颜色距离小于 15、连通面积至少 5 像素的可见性追踪；5266 帧均有目标色分量。只有 `seed10900301/frame229` 同时出现面积 5 和 110 的两个分量，小分量位于图像顶部，不能机械解释为第二个目标。取最大分量后，各视频相邻帧质心最大位移为 1.56～3.54 像素，没有身份跳跃迹象。
- 固定源码中的正式生成与官方评估入口都每条新建环境，再 reset、运行、close；没有命中复用同一环境后 `static_flag` 不清的风险。不能把该 API 潜在风险列作本批数据缺陷。

## 文件

- `h5-task-segments.json`：21 条真实 HDF5 的任务话术、演示标志及连续任务段。
- `xhard1-ep0-demo-frame105.png`：原视频截图，顶部第二句显示有歧义的话术。
- `identity-contact-index.json`：12 张身份联系图与输入视频路径。
- `*-identity.png`：每次抓取起点和临近结束的 RGB／原始分割／目标分割，保留帧号。
- `swap-visibility-traces.json`：5266 帧的分割颜色可见性与连通分量质心。

## 边界

颜色追踪来自已压缩的分割视频，而不是无损 actor-ID 张量；它证明这些可见片段的身份连续性，不构成任意策略动作下的形式化正确性证明。没有把成功字段或子目标文字单独当成视觉身份依据。`is_obj_dropped` 的宽松高度阈值属于独立判据风险，未在这些视频中找到实际语义错误案例。
