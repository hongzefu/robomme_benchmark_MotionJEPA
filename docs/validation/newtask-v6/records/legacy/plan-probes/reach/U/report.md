## 一、三路实测（本机，opus subagent 并行；详见 ../A ../B ../C 各自 report.md）

| 探针 | 量什么 | 规模 | 硬结论 |
|---|---|---|---|
| A 末端可达图 | 顶抓 / 夹爪推 / 带杆推起点三类 tcp 位姿，桌面 0.025 网格 × 8 个 yaw，真实规划器（screw；失败点另测 IK） | 57288 次，13 min | 全 yaw 可达 = 离基座 **0.31～0.80 m**；y=0 线上 x∈[−0.30, 0.175]；(0,0) 内切圆 R≈0.19；**yaw 不改变远近边界，只决定手腕能否转过去**；一步直达的 screw 漂移 1.6 cm，两段式 0.44 cm |
| B 抓杆可达图 | 杆根 0.025 网格 × 12 个 yaw，真调 `grasp_and_lift_peg_side`（含 xhard 翻转归约、RRT* 兜底） | 12276 次，16 min | 成败只看**抓取点（杆尾 = root − 0.10·u）离基座距离**：0.27～0.80 m 全成功，0.80～0.85 仅 48%，≥0.85 为 0，<0.25 也抓不到；按抓取点计 (0,0) 内切圆 0.20，按杆根只有 0.10 |

**对朝向问题的回答**：会影响，但只影响「手腕转不转得过去」（A：grasp 在 yaw=90° 时 screw 全灭、但 `solve_pickup` 取最近边使 yaw≡yaw+180°；push 在 yaw=270° 缺左上楔形，有 IK、RRT* 兜底），不改变远端 0.80 m / 近端 0.31 m 的硬边界。杆的 yaw 影响的是抓取点被杆身伸到哪里（B），所以约束要落在抓取点而不是杆根。

## 二、统一区域 U 的定义（`region.py`，参数 `gl/region_params.json`）

对**方块中心、goal 中心、杆抓取点**三者共用一个区域 U（桌面坐标，基座 (−0.615, 0)）：

| 条件 | 值 | 依据 |
|---|---|---|
| 离基座距离 | 0.35 ≤ \|p − base\| ≤ 0.76 | A/B 硬边界 0.31 / 0.80 各留 4 cm |
| 去掉桌心 | \|p\| ≥ R_IN = 0.14 | 「尽可能多去掉」：0.14 时 U 面积 0.186 m²，仍为 V5 方块框（0.040）的 4.7 倍；0.16 时 0.169 m² |
| 侧向 / 远近封顶 | \|y\| ≤ 0.30，−0.30 ≤ x ≤ 0.15 | A 图左上楔形、y=0 线上近端 −0.30、C 抓杆点 x>0.15 时 2/17 |
| 成对 | 0.10 ≤ \|方块 − goal\| ≤ 0.30；推起点（方块后退 0.10、带杆再侧移 ±0.10）也在 [0.35, 0.76] 内 | C：推距 >0.30 成功 12/22 |
| 杆 | 抓取点在 U 内均匀、yaw ∈ U(−π, π)，杆根 = 抓取点 + 0.10·u；杆身线段离桌心 ≥ R_IN；方块离杆身 ≥ 0.04、goal 离杆身 ≥ 0.02 | B；V5 已有的压杆缺陷 |
| 方块 yaw | U(0, 2π)（与 V5 相同，本来就是全随机） | C 核实 |

R_IN 扫描（`region.py` 主程序，各 1500 段）：

| R_IN | U 面积 m² | 占不挖中心的比例 | 平均尝试（杆/goal/方块） | 推距均值 | 方块离基座均值 |
|---|---|---|---|---|---|
| 0.08 | 0.228 | 0.92 | 1.2 / 1.0 / 5.2 | 0.194 | 0.538 |
| 0.10 | 0.216 | 0.87 | 1.2 / 1.0 / 5.5 | 0.192 | 0.533 |
| 0.12 | 0.203 | 0.82 | 1.2 / 1.0 / 6.6 | 0.189 | 0.529 |
| **0.14** | **0.186** | 0.75 | 1.3 / 1.0 / 7.1 | 0.186 | 0.528 |
| 0.16 | 0.169 | 0.68 | 1.4 / 1.0 / 9.0 | 0.177 | 0.525 |

## 四、结论
1. U 按 A/B/C 的硬边界定，GL 真演示 144 局证明**区域本身不再是失败来源**（grasp_putdown 100%，两种推法失败全是推动接触，与位置、离基座距离无关）。
2. 相比 V5 现状：方块/goal 的采样面积从 0.040 / 0.048 m² 扩到 0.186 m²，杆根从两个 ±0.05 小框扩到整个 U（按抓取点约束），三者统一；桌心 0.14 m 内完全不放东西。
3. 待用户定：R_IN 取 0.14（建议）还是 0.16；推距上限 0.30 是否保留（去掉会让 gripper_push 回到约 55%）。
