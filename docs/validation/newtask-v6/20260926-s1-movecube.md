# V6 S1：MoveCube 圆环区域迁移

本记录对应 V6 定稿 MoveCube xhard4 区域 U 的主树集成。实现复用副本 `v6-draft-movecube` 的几何约束；主分支当前 HEAD 在此步骤开始前为 `535a021`，MoveCube 与公共管道适配按本仓库最新版本号顺延提交。

## 改动

- `src/robomme/robomme_env/MoveCube.py` 将新值档和规格键统一为 `xhard4`：`config_xhard4`、`demo_layout.xhard4.region`、`execution_layout.xhard4.region`、`peg_yaw_range.xhard4`、`_load_scene_xhard4_region`。`__init__` 在 `super().__init__` 前调用 `require_xhard4_only`，拒绝本环境不支持的 `xhard1..3`。
- 区域 U 保持定稿值：圆心 `(-0.06, 0)`、半径 `[0.12, 0.20]`、离基座 `[0.35,0.76]`、杆/goal净空 `0.04/0.02`、推距上限 `0.30`。方块中心、goal 中心、杆抓取点及推起点由同一套规则约束。
- `src/robomme/robomme_env/utils/object_generation.py` 增加 `spawn_random_cube` / `spawn_random_target` 可选区域参数：`annulus`、`base_band`、`segment_clearance`、`push_feasible`。这些参数默认 `None`，关闭时不进入新约束分支；MoveCube V6 配置显式启用。
- V5 snapshot 保持原样，SHA-256 `c45d4408a5b87d71a8be72d1724322f06d6801118bb53e4afdffd07b1eaf8315`。录制器未改。
