网站已在 [http://141.212.115.116:8060/](http://141.212.115.116:8060/) 上线，独立tmux会话为`v6-gradient-site-8060`。页面按16个任务逐个介绍各档难度梯度，包含71张难度卡片、251个视频文件。网站用于查看现有产物；**S3仍在进行，网站上线与浏览器通过不代表原三档对拍通过或V6正式接纳。**

## 内容与来源

13个梯度任务各有hard及xhard1～xhard4五张卡，MoveCube／InsertPeg／StopCube各有hard与xhard4两张卡，合计71张。视频来自合并清单中的165条新值成功轨迹以及S0基线的48条hard轨迹；一个轨迹可能有主视频与额外片段，故213条轨迹对应251个视频文件，不能把251写成轨迹成功数。

实际目录为 `artifacts/newtask-v6/site-v3/`：`catalog.json`保存公开任务／档位说明，`media-private.json`保存251个媒体映射，`posters/`保存251张CPU解码JPEG预览，`server.log`保存运行日志。35个极短片段采用0秒帧以保证预览有效；预览不启动环境、不新增轨迹。公开页面通过受限媒体入口访问视频，不把本机任意路径作为文件服务。

目录生成源码为 `scripts/parity/v6_site_catalog.py`，服务源码为 `scripts/parity/v6_site.py`，页面为 `scripts/parity/v6_site.html`。生成器默认读取合并成功清单 `artifacts/newtask-v6/s4-launch/verification/merged-provisional-delivery.json`、S0 `artifacts/newtask-v6/v1/base/results/B.json`和根目录V6计划。默认输出初版`artifacts/newtask-v6/site/`，当前线上使用v3，必须显式传目录。

## 还原命令与服务保留

以下为实际接口，已有目录和运行服务不重复覆盖或启动。生成器拒绝覆盖`catalog.json`／`media-private.json`；如需另建版本，应先选一个不存在的目录再显式传`--out`，不重跑生成轨迹：

```bash
UV_CACHE_DIR="$PWD/artifacts/cache/uv" uv run --no-sync python \
  -m scripts.parity.v6_site_catalog --out artifacts/newtask-v6/site-v3
```

上面是v3目录生成接口记录，当前目录已存在，直接重执行会被拒绝；生成器只生成目录JSON，JPEG预览为本轮另行完成的CPU处理产物，不声称该单条命令会生成预览。实际服务入口：

```bash
UV_CACHE_DIR="$PWD/artifacts/cache/uv" PYTHONUNBUFFERED=1 uv run --no-sync python \
  -m scripts.parity.v6_site --host 0.0.0.0 --port 8060 \
  --site-dir artifacts/newtask-v6/site-v3
```

该命令由 `artifacts/newtask-v6/site-v3/launch.sh` 在独立tmux会话`v6-gradient-site-8060`执行，使用pipefail、PYTHONUNBUFFERED、tee落盘，服务结束时记`EXIT_CODE`。本报告不复制sh或yaml到docs。服务持续运行时日志没有最终退出码是预期，不能写成“服务已退出0”。

查看会话使用`tmux has-session -t '=v6-gradient-site-8060'`或`tmux attach -t v6-gradient-site-8060`，后者用Ctrl-b d脱开。按当前要求保留网站会话与产物，不自动停止；未来若明确要求停止，只能精确操作这一会话，禁止全局tmux清理，也不触碰S3或集群占位作业。

## 实际验证与边界

真实浏览器脚本和结果为 `artifacts/newtask-v6/site-v3/browser_check.py`、`browser-result.json`。结果`status=PASS`：16任务均验证播放、seek和样例切换；卡片数71；搜索、移动导航、无表格检查通过，`page_errors=[]`。桌面截图为同目录`desktop.png`，移动截图为`mobile.png`，主代理已目视复核。

```text
SITE_CATALOG=PASS tasks=16 cards=71 videos=251
SITE_BROWSER=PASS tasks=16 play=16 seek=16 sample_switch=16 search=1 mobile_navigation=1 no_table=1 js_errors=0
SITE_HTTP=PASS head=1 range=1 traversal_rejected=1
SITE_PREVIEW=PASS jpeg=251 short_clip_zero_second=35
NATIVE_REGRESSION=PENDING
```

HTTP HEAD、Range分段请求与路径穿越拒绝由主代理完成验证；支持Range使浏览器能够跳转播放。浏览器交互并非仅静态文本检查，但每任务样例检查不等于逐个视频全片播放；251张预览只证明首帧可用，不证明所有帧内容和任务语义。S3真实验收另见[S3阶段报告](20260926-s3.md)，S4数据来源与失败保留见[S4报告](20260926-s4.md)。
