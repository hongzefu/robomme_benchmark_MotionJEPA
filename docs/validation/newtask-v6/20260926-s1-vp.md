# V6 S1：VideoPlace 梯度与单调检查

本记录对应 V6 定稿对 VideoPlaceButton 与 VideoPlaceOrder 的实现。主工作树分支 `newtaskRelease-v5`；本阶段继 pipeline、MoveCube 后集成 VPB/VPO 与单调检查入口。

## 定稿实现

- 原 easy/medium/hard 与原 hard 演示路径保持冻结。四个新值档只使用 `return_to_origin`；此实现按计划中的 hard 冻结及原 hard 表值执行。
- VPB 由 `extra_place_before/after` 在按钮前后增加非答案台目标段，target 放置次数为 `xhard1..xhard4 = 3/4/5/6`。末尾回家是共同收尾，不计入梯度。
- VPO 使用固定访问计数 `[2,3]`、`[3,3]`、`[3,4]`、`[4,4]`，各档目标访问总数为 `5/6/7/8`。只有两个计数不等时随机决定哪块访问较多；规格记录 `objects.visit_counts_by_object` 和 `actions.target_placement_count`。
- `validate_demo_plan` 限制新档返回策略，`vqa_options` 支持 target drop 候选。`v6_tier_monotone.py` 将静态表检查与实测检查分开：静态命令输出 `TIER_PLAN_TABLE`；真实样本入口 `--reset-all` 接收四档 `v4_specs draw` JSONL，检查13环境×4档、seed/spec SHA/identity、样本短缺、均值及相邻档区间。
