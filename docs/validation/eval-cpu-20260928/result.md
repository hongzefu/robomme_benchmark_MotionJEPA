## 一次启动与重复启动

已有席位内的5次`srun`分发延迟为0.095～0.158秒；与数十秒载模及首次调用相比很小。这里从登录节点记录的分发时间算到计算节点脚本开始，不含人工等待或聊天工具延迟。把10张卡的全部任务合到1张卡串行尚未测试，不能由这里宣称会更快。

## 当前评估链路

SimpleMemVLA 的 `scripts/gl_run_testhard.sh` 每片发一次 `srun`，`scripts/run_testhard.sh` 启动单轮进程；`robomme_sim/testhard_eval.py::main` 在身份循环前构建一次策略，片内逐局串行、正常局只关闭仿真环境。默认 `OMP_NUM_THREADS=1`、每次执行 16 个动作。单 CPU 分配并不意味着代码只有一个线程，实际 `InProcSimPool(1)` 包含线程池。

framesample 的 `scripts/gl_eval_shard.sh` 在每片启动一次 server，client 逐局串行，整片结束才收 server。来自 `b22fc9c1ec73584870342c6335676a63dc417f9e` 的入口；不同正式轮重新启动 server。既有两条链路都不是逐局重新申请 GPU 或逐局加载模型。

SimpleMemVLA 两轮20份原始日志首行进一步确认：分片0～9两轮均复用占位作业62177614～62177623。第二轮没有重新`sbatch`排队；重复的是已有席位内的`srun`、Python启动和模型加载。不能把轮间编排空档算成GPU申请延迟。

历史正式分片每轮为 xhard1/2/3 各 13 任务×10 局 + xhard4 16 任务×10 局 =550 局，分到10张卡；xhard1～3缺 StopCube、InsertPeg、MoveCube，三任务仅xhard4。每片55局，但耗时不均衡：SimpleMemVLA 第一轮逐局 `elapsed_s` 合计最短4713.0秒、最长6326.4秒；第二轮最短5155.8秒、最长6817.6秒。它们不含模型初始化或局间关闭，仅说明同局数不能保证同工作量。旧日志缺时间戳，无法可靠还原模型加载时间；两轮之间的人工编排间隔不能当 Slurm 或 CPU 延迟。

两轮片均工作量分别为5641.6秒和5865.7秒。假设能完美均衡且不增加调度成本，相对最慢片的理论缩短上界分别为684.8秒、951.9秒（11.4／15.9分钟）。不是已实现的调度加速，也没有实测动态队列。

## 比较边界

CPU进程时间是所有线程之和，不能用墙钟减CPU时间计算GPU等待率。相同身份与种子也不能替代相同工作量：报告须逐项核对demo帧数、动作步数、推理次数、终态。首次推理与后续稳态调用分开，演示回放计入reset。所谓冷启动只指新进程，不清系统页缓存，也不声称NFS冷缓存。

首个失败冒烟观察器每次事件同步追加NFS小文件；审查发现潜在干扰后，后续观察器改为进程内缓存、退出一次写入。该失败冒烟不进入正式吞吐对比。所有观察器仍有计时调用开销，没有独立开关对照，不能声称零干扰。

## 一次性任务的经验与验收

- 把资源分配、`srun`、Python导入、载模、端口就绪、首动作、后续调用分开。原有资源已跨轮复用，优化目标应是进程与模型生命周期，而不是重复解决不存在的逐局排队。
- 不把只读导入探针与GPU实跑步骤交叠。本次重叠约1秒后遇到计算模式异常，因果尚未单独证明；严格串行后framesample正常运行。SimpleMemVLA补跑需要新的明确授权。
- GL兼容性必须在GL验证；本机导入成功不能证明其glibc兼容。临时uv依赖层只用于本轮，不能改坏原共享venv。
- server端口开放不等于首次推理就绪；前三次RPC都可能慢。日志明确提示1 CPU时单线程编译多个候选配置。
- 同身份不等于同轨迹。核对演示帧、步数、调用数与终态，再判断性能；不能用`wall-cpu`推算GPU等待比例。
- 原framesample入口可能捕获单局错误后以0退出。完成守卫必须重读逐局JSON，检查身份精确集合、正常终态和规格绑定，缺字段不能当零；9项无仿真夹具覆盖合法失败与各类异常。

`BENCHMARK_ANCHOR=PASS files=3990 mismatches=0`；`FRAMESAMPLE_ANCHOR=PASS files=210 mismatches=0`，逐Git blob核验快照字节，记录在`records/anchor-checks.json`。不将此读成数值逐位一致。`FRAME_COMPLETION=PASS`覆盖2任务×1档×（3个CPU档+1次独立启动）=8次，正常结果文件及每组退出码0在`records/`；`SIMPLEMEM_SMOKE=FAIL attempts=1 exit_code=3`，未隐藏失败。
