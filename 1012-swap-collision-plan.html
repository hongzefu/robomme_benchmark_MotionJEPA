1012-swap-collision-plan.html — 交换类 xhard 任务移植 v2.1 碰撞检测 + 发起者均匀化

权威性与锚点：本文件是本轮唯一权威计划，代码锚点 a512b889（2.56）之后的工作副本 /data/hongzefu/robomme_benchmark_newtask-v3-MotionJepa1006，分支 newtask-v3-MotionJepa1006；外部依赖锚点：origin/newtask-v2.1refractor commit ce72b04fdb7806dbc98de2baa3c92118b98e6902 的 src/robomme/robomme_env/utils/bin_collision.py（sha256 bbe87eec…302b）。commit 编号体例 <大>.<小> <中文描述>，从 2.58 接续。 授权边界：本计划 2026-10-12 经用户按 plan 文件逐字批准（ExitPlanMode，未提修改），视为开工令；后续每次合并与 GPU 验收按本计划第二部分执行，范围外一律不做。

本文件是 plan mode 的工具管理文件。获批后第一步（S0-HTML）把同一内容写成仓库根目录单文件 HTML 1012-swap-collision-plan.html（两个 <h1>、图由 opus 子代理画内联 SVG），再按第 11 条提交推送；之后的实施以 HTML 为权威计划。本文件只规划不实施。

〇、为什么改（引言）

  • 本分支 VideoUnmaskSwap / ButtonUnmaskSwap / VideoRepick 的交换动作用 swap_flat_two_lane 直接 set_pose 传送，没有任何碰撞检测，移动对象穿过第三个对象不报错、样本照常录制（2026-10-12 只读核查，已写进 readme.md 第九节）。
  • 远端 origin/newtask-v2.1refractor（commit ce72b04f）有一套纯几何判据 utils/bin_collision.py（899 行，只依赖 numpy），但绑在「离线规格注入」管线上。
  • 用户 2026-10-12 决定的口径（原话逐字）：
  • 「把v2.1的碰撞检测移植到v3 出个计划 最好不要离线传入 最好是在创建的过程中_load_scene再定」
  • 「在_load_scene先进行certify_swap_plan 配对逻辑完全照搬v2.1 … 如果无法生成 就报告failure 在正式执行的时候 也加入碰撞 如果碰撞也报failure」「每子步复核」
  • 「重新设定v3改 还是加入两组碰撞检测 一组初始化检测 一组执行中 还是找最近邻 但是发起需要尽可能均匀 发起者的选择尽可能不选择刚换过的两个 除非别无选择」
  • 四项裁决：「1 同意 并且这个是新特性（空容器可当发起者）2 随机（并列时）3 算搭档（次数计发起+搭档）4 同意（三项 P1 覆盖）」「写html plan」
  • 目标：能通过检测的样本交换动作与现在相同；会穿模的样本在 reset 或运行中被判 failure 剔除（固定 seed、不重试）；发起者分布均匀且不连续动同一对。

二、机制

2.1 reset 阶段：certify_swap_plan()（新增，src/robomme_xhard/swap_plan.py）

在三个子类 _load_scene 里 super()._load_scene(options) 与现有 check_swap_count(self) 之后调用：

  1. 取对象：actors = self.spawned_bins（VideoRepick 为 self.spawned_cubes），按生成序号编号 bin_0..bin_{N-1}；旁观者候选另含 ButtonUnmaskSwap 的 button_left/right、VideoRepick 的 button_left（见风险 R3：按钮碰撞体若非盒体则不入旁观者）。
  2. 读实际碰撞盒：object_state_from_actor(actor, name)（vendored）。
  3. 检测①-a 初态：check_bin_layout(states, stage="initial")，拒绝即 raise SwapCollisionError(rejection)。
  4. 逐段推演 k = 1…S（plan_swaps()，复刻 v2.1 _simulate_swaps，换掉发起者来源）： - 发起者 idx1[k] = select_initiator(usage, excluded={idx1[k-1], idx2[k-1]}, gen)（K3/K4）。 - 搭档 idx2[k] = nearest_partner(idx1[k], xy)（K2）。 - 检测①-b 路径：check_swap_sweep(cur[idx1], cur[idx2], bystanders, sweep_index=k-1)，拒绝即抛错。 - usage[idx1] += 1; usage[idx2] += 1；位姿表互换（A 落到 B 的 xy 并接手 B 的 q，z 各自保留，与 swap_flat_two_lane 收尾一致）。
  5. 写死配对：setattr(self, f"swap_pair{k}_idx1", actors[idx1[k]])、同理 idx2，k=1..S（覆写父类前三个 idx1，K8）；self._refresh_swap_schedule()。父类 step 看到 idx2 非 None 就不再现算。
  6. 留证：self._xhard_swap_plan = {"pairs":[{k, initiator, partner, distance_m, min_gap_m}], "usage":[...], "initial_gap_m":…}、self._xhard_runtime_checks = []。

独立随机流：gen = torch.Generator(); gen.manual_seed(int(self.seed) + 0x53_57_41_50)（常量 SWAP_PLAN_SEED_OFFSET），只用于 K3 的并列抽样，不触碰父类 _load_scene 的局部 generator（它已经用完返回）。

2.2 发起者规则示例（hard 四容器长方形 15×20 cm，忽略 ±7 cm 偏移，S=6）

容器 0、1 在短边一侧，2、3 在另一侧；最近邻恒为 0↔1、2↔3。

k 上段刚换过 候选池 usage [0,1,2,3] idx1 idx2
1 — {0,1,2,3} [0,0,0,0] 并列随机→设 2 2 3
2 {2,3} {0,1} [0,0,1,1] 并列随机→设 1 1 0

效果：相邻两段永远落在不同的一对上；S=11、N=4 时每对象参与次数差 ≤ 1。仍保留的退化（来自 K2，本轮不改）：长方形里只有短边两对互换，两段一轮后位置回到原处。

2.3 运行阶段（SwapCollisionMixin，K5/K8）

  • 检测②-a 段起点（覆写 step，在 super().step(action) 之前）：当 elapsed_steps == swap_schedule[k][2]：① 用实际位姿重算 idx1[k] 的最近邻，必须等于写死的 idx2[k]，不等抛 SwapBindingError（不现场换搭档）；② 从实际位姿 check_swap_sweep 整段重证，拒绝抛 SwapCollisionError。对应 v2.1 _verify_swap_binding + _check_swap_sweep_from_actual。
  • 检测②-b 每子步（覆写 _before_simulation_step / _after_simulation_step，先调 super()）：仅当 elapsed_steps 落在某段 [start, end] 内，对全部对象做 check_bin_layout(stage="substep_before"/"substep_after")，拒绝抛错；通过只追加 min_g_m。
  • 全部结果追加进 self._xhard_runtime_checks。

2.4 失败如何变成 failure（K6）

  • SwapCollisionError(SceneGenerationError)、SwapBindingError(SceneGenerationError) 定义在 src/robomme_xhard/collision/__init__.py，携带 rejection.as_dict()。
  • _load_scene 在 gym.make 内触发，生成器 _worker 的 try 块包住 gym.make/reset/_execute_tasks；SceneGenerationError 在 retryable 元组里 → failure_class="task"；xhard 卡 fixed_seed → 直接 exhausted、「固定 seed 不重试」。不改生成器的分类逻辑。
  • 生成器唯一改动：finally 里 record_env.close() 之前，若 unwrapped 有 _xhard_swap_plan / _xhard_runtime_checks 就复制进结果行字段 swap_plan、runtime_checks（成功与失败行都带）。

    def _swap_actors(self) -> list: raise NotImplementedError
    def _bystander_actors(self) -> list: return []
    def _swap_segment_index_at(self, step) -> int | None  # 返回 k-1 若 step == schedule[k][2]
    def _in_swap_window(self) -> bool                      # any(start <= step <= end)
    def step(self, action):
        k = self._swap_segment_index_at(int(self.elapsed_steps))
        if k is not None: self._check_segment_start(k)     # 绑定 + 整段重证
        return super().step(action)
    def _before_simulation_step(self): super()._before_simulation_step(); self._substep_check("substep_before")
    def _after_simulation_step(self):  super()._after_simulation_step();  self._substep_check("substep_after")

_check_segment_start(k)：initiator = getattr(self, f"swap_pair{k+1}_idx1")、expected = ..._idx2；recomputed, table = nearest_partner_index(pos(initiator), [(i,pos(a)) for i,a in enumerate(actors) if a is not initiator])；actors[recomputed] is not expected → SwapBindingError(detail)；再 check_swap_sweep(state[a], state[b], bystanders, sweep_index=k) 拒绝 → SwapCollisionError。证据追加 {"kind":"swap_binding"|"swap_sweep", "control_step", "sweep_index", "min_g_m", "rejection"}。

_substep_check(stage)：if not self._in_swap_window(): return；check_bin_layout(states, stage=stage)；拒绝 → SwapCollisionError。
