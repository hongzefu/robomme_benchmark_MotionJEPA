  • 「均匀」指 K3 均衡的是「发起 + 搭档」总参与次数，只在对称布局下成立（理想矩形、S=11、N=4 时每对象总次数差 ≤ 1）；结果统计分别记发起次数、搭档次数、总参与次数。
  • N=3（VideoRepick）：候选池恒为 1 个（全部 3 − 上段 2），k ≥ 2 的发起者被确定性轮转，测试只断言相邻对不同。
  • 仍保留的退化（来自 K2，本轮不改）：理想矩形里只有短边两对互换，偶数段数时每对被换偶数次、容器最终回到原位，待裁决 D1。

class SwapCollisionMixin:
    swap_name_prefix = "bin_"
    def _swap_actors(self) -> list: raise NotImplementedError
    def _bystander_actors(self) -> list: return []
    def _swap_segment_index_at(self, step) -> int | None  # 返回 k-1 若 step == schedule[k][2]
    def _in_swap_window(self) -> bool                      # any(start <= step <= end)
    def step(self, action):
        out = super().step(action)                         # 父类先落定上一段、捕获下一段端点、刷新 schedule
        k = self._swap_segment_index_at(int(self.elapsed_steps) - 1)   # 刚执行的这一步是否第 k 段 start（以父类步号口径为准，C1 实现时核对）
        if k is not None: self._check_segment_start(k)     # 绑定 + 端点对齐 + 整段重证
        return out
    def _before_simulation_step(self): super()._before_simulation_step(); self._substep_check("substep_before")
    def _after_simulation_step(self):  super()._after_simulation_step();  self._substep_check("substep_after")

_check_segment_start(k)（在 super().step 返回后调用，此刻上一段已在 cur==end 落定、本段在 cur==start 捕获端点且 alpha=0 未位移）：initiator = getattr(self, f"swap_pair{k+1}_idx1")、expected = ..._idx2；recomputed, table = nearest_partner_index(pos(initiator), [(i,pos(a)) for i,a in enumerate(actors) if a is not initiator])；actors[recomputed] is not expected → SwapBindingError(detail)；核对证书输入的 p/q 与父类 _two_lane_swaps 缓存端点逐项一致（记入证据，供 XHARD_SEG_START_ALIGN）；再 check_swap_sweep(state[a], state[b], [state[i] for i 不在 {a,b}] + bystander_states, sweep_index=k)——旁观者是本段未参与交换的其余交换对象 + 外部旁观者，与 reset 时 plan_swaps 一致；拒绝 → SwapCollisionError(stage="sweep_actual")。证据追加 {"kind":"swap_binding"|"swap_sweep", "control_step", "sweep_index", "gap_lower_bound", "endpoint_match", "rejection"}。
